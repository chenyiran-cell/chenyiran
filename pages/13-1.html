② 尺寸控制（CSS font-size）

字体图标本质是文字，直接用 font-size 控制大小，或用 FA 内置类 fa-2x ~ fa-10x。

③ 颜色控制（CSS color）

同样因为是文字，直接用 color 改颜色，支持渐变、阴影等所有 CSS 文字效果。

④ 动画效果（CSS Animation）

Font Awesome 内置 fa-spin、fa-pulse 动画类，也可自定义 CSS 动画。

⑥ 字体图标 vs SVG 图标

✅ 字体图标（Font Awesome）

  • 用 CSS 类名使用，简单快捷
  • 用 font-size / color 控制样式
  • 一次加载字体文件，图标数量多
  • 不支持多色图标
  • 旧浏览器兼容性好

🎨 SVG 图标（Lucide）

  • 内联 SVG，可精确控制每个路径
  • 支持多色、渐变、描边动画
  • 按需加载，无额外字体请求
  • 可被 CSS / JS 精确操控
  • 矢量无损缩放
