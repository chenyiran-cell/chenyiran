JSON 入门

作者：陈依然 · 点击按钮即时体验

一、什么是 JSON

JSON（JavaScript Object Notation）是一种轻量级数据交换格式。长得像 JS 对象，但有严格语法：

{ "name": "陈依然", "age": 21, "hobbies": ["编程", "音乐"], "address": { "city": "大连", "zip": "116000" } }

二、JSON 语法规则

#规则示例
1键名必须用双引号"name": "张三" ✅
2字符串也用双引号（不是单引号）"hello" ✅ / 'hello' ❌
3末尾不能有多余逗号[1, 2,] ❌
4不允许注释（// 或 /* */ 都不行）被 JSON5 扩展支持
5值类型：字符串、数字、布尔、null、对象、数组undefined ❌ NaN ❌ 函数 ❌

三、把 JSON 字符串 → JS 对象：JSON.parse()

// JSON 字符串（从后端来的） const jsonStr = '{"name":"陈依然","age":21}'; // 解析成 JS 对象 const obj = JSON.parse(jsonStr); console.log(obj.name); // "陈依然"
—
// 非法 JSON 会报错！ try { JSON.parse('{name: 123}'); } catch(e) { console.error("解析失败", e.message); }
—

四、把 JS 对象 → JSON 字符串：JSON.stringify()

const user = { name: "陈依然", age: 21, email: "chen@test.com" }; const json = JSON.stringify(user); console.log(json); // {"name":"陈依然","age":21,"email":"chen@test.com"} // 美化输出（2 空格缩进） const pretty = JSON.stringify(user, null, 2);
—
// 自定义序列化：replacer 函数 const withFunc = { a: 1, b: 2, fn: () => 3 }; JSON.stringify(withFunc); // 函数直接被忽略！输出 {"a":1,"b":2} // undefined 也会被忽略 JSON.stringify({ x: 1, y: undefined }); // {"x":1}
—

五、经典用法：用 JSON 实现深拷贝

const original = { a: { b: 1 } }; // 浅拷贝（只拷贝一层） const shallow = Object.assign({}, original); shallow.a.b = 999; console.log(original.a.b); // 999 ← 被污染了！ // JSON 深拷贝（先序列化再解析） const deep = JSON.parse(JSON.stringify(original)); deep.a.b = 999; console.log(original.a.b); // 1 ← 独立副本 ✅
—

六、完整流程：从后端 fetch JSON → 解析 → 使用

// 1. fetch 拿到响应 fetch('https://dummyjson.com/products/1') // 2. 调用 .json() 自动 parse .then(res => res.json()) // 3. 拿到 JS 对象，随意用 .then(data => { console.log(data.title); console.log(JSON.stringify(data, null, 2)); }) .catch(err => console.error(err));
—
