Web 前端长度单位

CSS 常用长度单位交互演示 · 拖动滑块或调整参数查看效果

px（像素）绝对单位

1px 是屏幕上的一个物理像素点（CSS 逻辑像素），大小固定，不随父元素或视口变化。

宽度：200px

em（相对父元素字体大小）相对单位

相对父元素字体大小的倍数。父元素字体为 20px 时，2em = 40px。下面两个盒子父元素字体不同，2em 结果也不同。

10em（父 16px → 160px）
10em（父 24px → 240px）

提示：em 常用于 padding / margin / 行高等场景，便于整体缩放。

rem（相对根元素字体大小）相对单位

始终相对 <html>（根元素）的字体大小。拖动滑块改变根字体，观察盒子变化：

宽度：10rem

当前 10rem = 160px

提示：移动端适配常用 rem + 动态修改 html 字体大小实现整体等比缩放。

%（百分比）相对单位

相对父元素对应属性的百分比。宽度相对父宽，字体大小相对父字体大小。

宽：父容器的 60%

vw / vh（视口宽 / 高）相对视口

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。缩放浏览器窗口即可看到效果。

30vw × 30px
200px × 15vh

当前视口：

宽：- px

高：- px

30vw = -px
15vh = -px

vmin / vmax相对视口

vmin = vw、vh 中较小者的 1%；vmax = 较大者的 1%。适合做正方形自适应。

25vmin 正方形
15vmax 正方形

视口 - × -

25vmin = -px
15vmax = -px

ch（字符宽度）相对单位

相对数字 "0" 字符的宽度，常用于限制文本行宽（如 60ch ≈ 每行 60 个字符）。

40ch：一段示例文本，观察宽度与字符数的关系。
