Lucide 图标

SVG 图标方案 · 通过 JavaScript 动态生成内联 SVG，可精确控制每个路径

① 基础图标（SVG 内联渲染）

Lucide 通过 lucide.createIcons() 将 <i data-lucide="xxx"> 替换为内联 SVG。 每个图标都是纯 SVG 路径，可用 CSS 精确控制。

② 尺寸控制（width / height）

SVG 图标通过 width 和 height 属性控制大小，完美矢量缩放。

③ 颜色控制（color / stroke）

Lucide 图标默认使用 stroke="currentColor"，自动继承文字颜色，也可用 CSS color 或 stroke 覆盖。

④ 描边宽度（stroke-width）

Lucide 默认 stroke-width="2"，可调整为 1（细线）、3（粗线）等不同风格。

⑤ 动画效果（CSS Animation）

因为是 SVG，可以用 CSS 变换、SMIL 或 JS 实现旋转、缩放、描边动画等效果。

⑥ 实际应用场景

图标在按钮、列表中的常见用法。

⑦ SVG 源码结构

Lucide 图标渲染后的 SVG 结构如下，每个图标由多个 <path> / <circle> 等元素组成：

<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <path d="M3 9l9-7 9 7v11a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"/>
  <polyline points="9 22 9 12 15 12 15 22"/>
</svg>
