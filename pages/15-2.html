一、条件结构（分支）

1. if ... else if ... else条件

const cyr_score = 85; if (cyr_score >= 90) { // 优秀 } else if (cyr_score >= 80) { // 良好 } else if (cyr_score >= 60) { // 及格 } else { // 不及格 }

2. 三元运算符 ? :条件

条件 ? 值1 : 值2 是 if...else 的简写，适合简单的二选一赋值。判断一个数是奇数还是偶数。

const cyr_n = 7; const cyr_result = (cyr_n % 2 === 0) ? '偶数' : '奇数';

3. switch ... case条件

对一个值做多路严格相等匹配，注意每个 case 末尾要加 break，否则会"穿透"到下一个分支。输入 1~7 输出星期几。

const cyr_day = 3; switch (cyr_day) { case 1: cyr_text = '星期一'; break; case 2: cyr_text = '星期二'; break; case 3: cyr_text = '星期三'; break; // ... case 4 ~ 6 ... default: cyr_text = '星期日'; }

二、循环结构（迭代）

4. for 循环循环

三要素：初始化; 条件; 步进。循环次数确定时首选。演示：计算 1+2+…+100 的和。

let cyr_sum = 0; for (let cyr_i = 1; cyr_i <= 100; cyr_i++) { cyr_sum += cyr_i; }

5. while 循环循环

先判断后执行，条件为 false 时一次都不执行。适合循环次数未知的场景。演示：不断折半，看 1000 几次后小于 1。

let cyr_val = 1000, cyr_times = 0; while (cyr_val >= 1) { cyr_val /= 2; cyr_times++; }

6. do ... while 循环循环

先执行后判断，循环体至少执行一次。演示：模拟掷骰子，直到掷出 6 点为止，记录掷了几次。

let cyr_dice, cyr_count = 0; do { cyr_dice = Math.floor(Math.random() * 6) + 1; cyr_count++; } while (cyr_dice !== 6);

7. for...of 与 for...in循环

for...of 遍历数组的值；for...in 遍历对象的键。两者不要混用。

const cyr_fruits = ['苹果', '香蕉', '橙子']; for (const cyr_f of cyr_fruits) { /* 拿到值 */ } const cyr_user = { name: '陈依然', age: 20 }; for (const cyr_k in cyr_user) { /* 拿到键 */ }

8. break 与 continue循环控制

break 直接结束整个循环；continue 跳过本次进入下一轮。演示：1~20 中跳过 3 的倍数（continue），遇到 16 提前停止（break）。

const cyr_list = []; for (let cyr_i = 1; cyr_i <= 20; cyr_i++) { if (cyr_i % 3 === 0) continue; // 跳过 3 的倍数 if (cyr_i > 15) break; // 16 起停止 cyr_list.push(cyr_i); }
