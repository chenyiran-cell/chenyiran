⏱️ setTimeout vs setInterval

作者：陈依然 · 两种定时器 · 实时演示 + 代码对照

📖 一句话区分

setTimeout(fn, delay) —— 一次性定时器，delay 毫秒后只执行一次就结束。像 sleep(1000)。

setInterval(fn, delay) —— 循环定时器，每隔 delay 毫秒反复执行，直到手动 clearInterval。像闹钟。

⚠ 两个都是异步的，不会阻塞主线程；返回一个定时器 ID 给 clearTimeout / clearInterval 取消。

⏰ setTimeout 一次性
等待触发…
设置 delay 后点「开始」，倒计时到 0 触发
let timerId; function start() { timerId = setTimeout(() => { console.log("时间到！"); }, 3000); // 3 秒后执行一次 } function stop() { clearTimeout(timerId); // 取消 }
延迟 秒
⏱️ setInterval 循环
0
累计触发次数（每秒 +1）
let counter = 0; let timerId2; function startCount() { timerId2 = setInterval(() => { counter++; console.log("tick", counter); }, 1000); // 每秒重复 } function stopCount() { clearInterval(timerId2); // 停止循环 }
间隔 秒
⚖️ 经典对比：用 setTimeout 代替 setInterval
// ❌ setInterval 版（如果 fn 里有耗时操作，下一次触发会"堆积"） setInterval(fn, 1000); // ✅ setTimeout 递归版（等上次执行完再触发下次，永不堆积） function loop() { doHeavyWork(); // 先干活（哪怕花了 1.5 秒） setTimeout(loop, 1000); // 干完再等 1 秒 } loop(); // 启动 // 💡 实战口诀：要循环干活，别用 setInterval，用递归 setTimeout！
