JavaScript 基础数据类型

7 种原始类型（Primitive）+ 1 种引用类型（Object）· 交互演示

小知识：传统说法是"JavaScript 有 6 种基础数据类型"（String / Number / Boolean / Null / Undefined / Object）， 但 ES6 新增了 Symbol，ES2020 新增了 BigInt。 按 ES2024 规范，JavaScript 共有 7 种原始类型 + Object 引用类型。 下方逐个演示，点击"运行"按钮实时查看结果。
STRING 字符串 原始类型

由引号包裹的文本序列，支持单引号 ' '、双引号 " " 和模板字符串 ` `（可插值）。 字符串是不可变的，任何操作都会产生新字符串。

const cyr_s1 = 'Hello'; const cyr_s2 = "World"; const cyr_name = '陈依然'; const cyr_s3 = `姓名：${cyr_name}，今年 ${25} 岁`; console.log(typeof cyr_s1, cyr_s1.length, cyr_s3);

NUMBER 数字 原始类型

JavaScript 中唯一的数字类型，底层始终是 64 位浮点数（IEEE 754）。 整数、小数、负数、科学计数法都是 Number。NaN（Not-a-Number）和 Infinity 也是 Number。

const cyr_int = 42; const cyr_float = 3.14; const cyr_neg = -100; const cyr_sci = 1e10; // 科学计数法 const cyr_nan = 0 / 0; // NaN const cyr_inf = 1 / 0; // Infinity console.log(typeof cyr_int, cyr_sci, cyr_nan, Number.isSafeInteger(cyr_int));

BOOLEAN 布尔值 原始类型

只有两个值：true 和 false。常用于条件判断。 JavaScript 中所有值都可隐式转换为布尔值，规则如下： false / 0 / -0 / 0n / '' / null / undefined / NaN → false，其余全部 → true。

const cyr_ok = true; const cyr_no = false; const cyr_cmp = (10 > 5); // 比较产生布尔 console.log(typeof cyr_ok, cyr_cmp, !true); // 真值（Truthy）与假值（Falsy）演示 [0, '', null, undefined, NaN, 'hello', 42].forEach(v => { console.log(v, typeof v, !!v); });

UNDEFINED 未定义 原始类型

变量已声明但未赋值时的默认值。函数没有返回值时也返回 undefined。 注意：typeof undefinedVar === 'undefined' 可以安全地检测未声明的变量（不会抛错）。

let cyr_declared; // 声明但未赋值 console.log(cyr_declared, typeof cyr_declared); function cyr_noReturn() {} // 没有 return 语句 console.log(cyr_noReturn()); // 安全检测未声明变量 console.log(typeof cyr_xxxNotExist);

NULL 空值 原始类型

唯一值为 null，表示"无对象"或"空引用"。 历史遗留 Bug：typeof null === 'object'（永远如此，无法修复）。 正确检测方式：value === null。

const cyr_empty = null; console.log(typeof cyr_empty, cyr_empty === null); // null vs undefined console.log(null == undefined); // true（宽松相等） console.log(null === undefined); // false（严格相等）

SYMBOL 符号 原始类型（ES6）

ES6 新增的原始类型，调用 Symbol(描述) 创建，每次调用都返回唯一值。 常用于对象私有属性、常量枚举、或作为对象键避免键名冲突。 typeof symbol === 'symbol'。

const cyr_s1 = Symbol('id'); const cyr_s2 = Symbol('id'); console.log(cyr_s1 === cyr_s2, typeof cyr_s1); // 用作对象的私有键 const cyr_private = Symbol('secret'); const cyr_obj = { name: 'test', [cyr_private]: 42 }; console.log(Object.keys(cyr_obj)); // Symbol 键不会被普通遍历

BIGINT 大整数 原始类型（ES2020）

ES2020 新增，用于表示 Number 无法精确表示的超大整数。 数字末尾加 n 即为 BigInt：9007199254740993n。 不能与普通 Number 直接混合运算（会抛错）。

const cyr_big = 9007199254740993n; // 末尾加 n const cyr_normal = 9007199254740993; // Number 无法精确表示 console.log(typeof cyr_big, cyr_big, cyr_normal); // 大整数运算 console.log(cyr_big + 1n);

OBJECT 对象（引用类型） 引用类型

唯一的引用类型（Reference Type）。Array、Function、Date、RegExp 等内置类型本质上都是 Object 的子类型。 与原始类型的区别：原始类型按值传递，Object 按引用（内存地址）传递。

// 原始类型：值传递 let cyr_a = 10; let cyr_b = cyr_a; cyr_b++; console.log(cyr_a, cyr_b); // 10, 11（互不影响） // Object：引用传递 const cyr_o1 = { v: 10 }; const cyr_o2 = cyr_o1; cyr_o2.v++; console.log(cyr_o1.v, cyr_o2.v); // 11, 11（同一个对象） console.log(typeof {}, typeof [], typeof function(){}); console.log(Array.isArray([]));
