fetch 获取跨域接口数据

作者：陈依然 · 演示完整 fetch 流程

一、接口地址

🏠 随机用户 API：https://randomuser.me/api/?results=6
✅ 支持 CORS，无需鉴权，完全免费

二、核心代码

async function fetchUsers() { try { const res = await fetch('https://randomuser.me/api/?results=6'); if (!res.ok) throw new Error('HTTP ' + res.status); const data = await res.json(); return data.results; } catch (err) { console.error(err); } }
