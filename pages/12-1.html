① 主题切换（变量覆盖）

在 :root 定义变量，通过切换 data-chen_theme 覆盖整组变量，实现一键换肤。

🎨 当前主题

浅色模式（light）

🔧 实现原理

:root 中定义变量 → html[data-chen_theme="dark"] 覆盖变量 → 所有引用 var(--chen_xxx) 的元素自动更新

④ 变量作用域（Scope）

变量遵循 CSS 级联规则：子元素可覆盖父元素变量，且只影响其后代。内层盒子用局部变量 --chen_local 覆盖了外层同名变量。

外层（使用 --chen-primary）

背景色来自 var(--chen-primary) = #6c5ce7

内层（覆盖 --chen_local = #e17055）→ 只影响此元素及其子元素

⑤ CSS 变量核心语法速查

语法说明示例
--name: value;在 :root 或元素上定义变量--chen_color: #6c5ce7;
var(--name)引用变量值color: var(--chen_color);
var(--name, 默认值)变量不存在时使用默认值color: var(--chen_x, #333);
calc()变量参与计算padding: calc(var(--chen_gap) * 2);
选择器覆盖在特定选择器中重新赋值html[dark] { --chen_bg: #111; }

提示：CSS 变量是运行时计算的（不是编译期），支持级联、继承和 JS 动态修改（setProperty）。
