JavaScript 对象 & 字符串

作者：陈依然 · 点击标签页切换主题，按钮即时体验

一、创建与检测

对象是 JS 的核心数据结构，属性可以是任何类型

字面量 / new Object()

推荐用字面量 { } 创建对象。

—
typeof / instanceof

检测类型。注意 typeof null === 'object' 是历史 Bug！

—

二、属性的增删改查

用 . 或 [ ] 访问，delete 删除

点符号 . / 方括号 [ ]

方括号支持变量作为键名、以及特殊字符/数字开头的键。

—
增 / 改 / delete

直接赋值即可新增或覆盖属性。delete obj.key 彻底删除属性。

—
in / hasOwnProperty

'key' in obj 检测原型链上是否存在；hasOwnProperty 只检测自身。

—

三、静态方法 Object.*

直接用 Object.xxx(obj) 调用

Object.keys(obj)

返回所有可枚举自身键组成的数组。最常用！

—
Object.values(obj)

返回所有可枚举自身值组成的数组。ES2017+。

—
Object.entries(obj)

返回键值对数组 [['key','val'], ...]，配合 for...of 遍历。

—
Object.assign(tgt, ...src)

把多个源对象的可枚举属性拷贝到目标对象，修改 target。

—
Object.create(proto)

创建一个新对象，原型指向 proto。实现原型继承。

—
Object.freeze(obj)

冻结对象：禁止增删改。Object.isFrozen 可检测。

—
展开语法 ...obj

ES6+：{...obj} 创建对象浅拷贝；可合并多个对象（后面的覆盖前面）。

—

一、基础属性与查找

字符串是不可变的原始类型（primitive），所有方法都返回新字符串

.length

返回字符串长度（字符数，UTF-16 单位）。

—
.includes() / .indexOf()

includes：是否包含（布尔）。indexOf：首次出现位置，找不到返回 -1。

—
.charAt(i) / [i]

获取指定位置的字符。[i] 是 ES6+ 推荐方式（charAt 返回空字符串更安全）。

—
.startsWith() / .endsWith()

判断字符串是否以指定子串开头或结尾，返回布尔值。ES2015+。

—

二、截取与切片

.slice(start, end)

最灵活的截取方法。start 到 end（不含），支持负数索引（从尾部数）。

—
.substring(a, b)

类似 slice 但不支持负数（负数当作 0），会自动把小的当 start。

—
.substr(start, len)

已废弃（deprecated），不推荐新代码使用。用 slice 或 substring 代替。

—

三、变换方法

.toUpperCase() / .toLowerCase()

转大写 / 小写，返回新字符串（原字符串不变！）。

—
.trim() / .trimStart() / .trimEnd()

去除首尾空白（空格、Tab、换行），常用于表单输入清理。

—
.replace(search, replace)

替换匹配的子串。字符串搜索只替换首次，要全局替换必须用 正则表达式 加 g 标志。

—
.split(sep)

按分隔符拆分字符串为数组。配合 .join() 形成经典组合。

—
.repeat(n)

把字符串重复 n 次后返回。ES2015+。padStart / padEnd 是填充版。

—

四、模板字符串

`Hello ${name}, age is ${20 + 5}`

用反引号 ` 包裹，${ } 中可以写任何 JS 表达式（变量、运算、函数调用等）。支持多行！
